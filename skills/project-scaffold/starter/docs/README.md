# Documentation

Versioned source of truth for this project. Working artifacts that must not be
committed go in `tmp/<work-item>/` at the repository root instead.

| Directory | Contents |
| --- | --- |
| `00_templates/` | Reusable document templates |
| `01_product/` | Purpose, users, and value |
| `02_requirements/` | Functional and non-functional requirements, acceptance criteria |
| `03_spec/` | Architecture, data, APIs, operations |
| `04_decisions/` | Decision records: context, decision, rationale, rejected options |
| `05_discussions/` | Unresolved questions and research |
| `06_execution/` | Delivery plans, QA, releases, operations |
